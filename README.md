# Marvellous Security Lab

My security engineering lab where I build and document 
production-ready detection logic, vulnerability management 
workflows, and security automation solutions. The lab showcases 
custom detections and security use cases I independently research 
and develop — addressing gaps that standard platforms don't cover 
out of the box.

## What's inside
- **Custom Detection Rules -** — Research custom rules 
- **KQL Detections** — Microsoft Sentinel rules mapped to MITRE ATT&CK
- **Vulnerability Management** — scanning, tracking, and remediation workflows
- **PowerShell Scripts** — Incident response and automation 
- **Python Tools** — Threat hunting, scripting and log analysis
